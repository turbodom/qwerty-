# Онлайн-стратегия для Pi Network: концепция и технический план

Рабочее название: **«Короны Пустоши»** (можно заменить). Важно: название и домен не должны начинаться с «Pi» (требование Pi к брендингу).

## 1. Концепция игры

Пошаговая фэнтези-стратегия в духе «Героев 3» для 2–4 игроков онлайн, адаптированная под телефон (Pi Browser).

**Основной цикл**
1. Игрок ведёт героя по карте приключений, собирает ресурсы, захватывает шахты, находит артефакты.
2. В замке строит здания, нанимает отряды (7 уровней существ на фракцию).
3. При встрече с нейтралами или другим игроком начинается тактический бой на гексагональном поле: отряды ходят по инициативе, у героя есть заклинания.
4. Победа: захват всех замков противника или уничтожение его героев.

**Что упростить по сравнению с «Героями 3» ради мобильного онлайна**
- Карты меньше (36×36 клеток), партия 30–60 минут.
- Ход ограничен таймером (например, 90 секунд), плюс режим асинхронной игры: сделал ход, закрыл приложение, получил уведомление, когда снова твоя очередь.
- Одновременные ходы на карте приключений (как в HotA-онлайне), пошаговость только в бою. Это сильно сокращает ожидание.
- Автобой для боёв с нейтралами.

**Артефакты и снаряжение героя**
- 10 слотов, как в «Героях 3»: голова, шея, плечи, торс, правая рука (оружие), левая рука (щит), 2 кольца, ноги, плащ, плюс рюкзак без ограничений.
- 4 редкости: обычные (+1 к навыку), редкие (+2–3), эпические (+4–5 или особое свойство), легендарные (сильные эффекты, например +1 к скорости всех отрядов или бессмертие одного отряда раз за бой).
- Наборы: 3–5 предметов одного комплекта дают бонус, например «Доспех Пепельного рыцаря» даёт +25% урона Людям.
- Где взять: на карте под охраной монстров, в сундуках, за победы над героями, в награду за сезон и за Pi в магазине (решение владельца, см. раздел 6).
- Стартовый набор: 40–50 артефактов, новые выходят каждый сезон.

**Фракции для старта:** 2 (например, «Люди» и «Нежить»), позже 4–6.

**Монетизация:** игра бесплатная, доход приносят прокачка героя и артефакты за Pi, косметика, боевой пропуск, премиум-аккаунт, платный одиночный контент и реклама. Подробно в разделе 6.

**Авторские права:** графику, музыку и названия из «Героев 3» использовать нельзя (права Ubisoft). Нужна своя графика: заказ у художника, лицензированные ассет-паки (itch.io, CraftPix) или AI-генерация с последующей доработкой.

## 2. Что требует Pi Network

- Приложение это обычный веб-сайт (HTTPS), открывающийся в Pi Browser. Регистрируется в Developer Portal (открывается в Pi Browser по адресу `develop.pi`).
- SDK подключается скриптом `https://sdk.minepi.com/pi-sdk.js`, инициализация `Pi.init({ version: "2.0", sandbox: true })` при разработке.
- **Вход только через Pi:** `Pi.authenticate(["username", "payments"], onIncompletePaymentFound)`. Сервер проверяет полученный accessToken запросом `GET https://api.minepi.com/v2/me`.
- **Платежи только в Pi**, схема из трёх шагов:
  1. Клиент: `Pi.createPayment({ amount, memo, metadata }, callbacks)`.
  2. `onReadyForServerApproval(paymentId)`: наш сервер вызывает `POST /v2/payments/{id}/approve` с ключом Server API Key.
  3. `onReadyForServerCompletion(paymentId, txid)`: сервер проверяет и вызывает `POST /v2/payments/{id}/complete`, после чего выдаёт покупку.
  Незавершённые платежи обязательно дожимаются в `onIncompletePaymentFound`.
- Выплаты игрокам (app-to-user) SDK поддерживает, но для MVP не нужны.
- **Для листинга в Mainnet:** KYC разработчика, рабочее приложение с аккуратным интерфейсом, только Pi-авторизация и Pi-платежи, никаких перенаправлений на внешние сайты, минимальный сбор данных, свой брендинг без логотипа Pi. Нужны политика конфиденциальности и условия использования.
- Разработка идёт на Testnet (тестовые Pi), в Mainnet выходим после проверки.

## 3. Технический стек

| Слой | Выбор | Почему |
|---|---|---|
| Язык | TypeScript везде | Одна кодовая база правил для клиента и сервера |
| Клиент | Phaser 3 + Vite | Зрелый 2D-движок для браузера, тайловые карты, спрайты, хорошо работает на телефонах |
| Интерфейс меню | HTML/CSS поверх канваса (или Preact) | Лобби, магазин, профиль проще делать в DOM |
| Мультиплеер | Node.js + Colyseus | Готовые комнаты, матчмейкинг, синхронизация состояния, переподключение |
| Правила игры | Отдельный пакет `shared/` с детерминированной логикой | Сервер авторитетный, клиент использует те же правила для подсказок и анимаций |
| База данных | PostgreSQL | Игроки, покупки, история матчей, сохранения асинхронных партий |
| Кэш/очереди | Redis | Матчмейкинг, масштабирование Colyseus на несколько процессов |
| Хостинг | VPS или Fly.io/Render, домен с HTTPS | Pi требует HTTPS-адрес |
| Карты | Tiled (редактор) → JSON | Бесплатный стандарт для тайловых карт |

**Архитектура мультиплеера**
- Сервер авторитетный: клиент шлёт только намерения («переместить героя в клетку X», «атаковать отряд Y»), сервер проверяет по правилам и рассылает новое состояние. Это защищает от читов.
- Одна комната Colyseus = одна партия. Состояние партии периодически сохраняется в PostgreSQL, чтобы асинхронные партии переживали перезапуск сервера.
- Туман войны: каждый игрок получает только видимую ему часть карты.
- Бой: отдельная подкомната или режим внутри партии; при бое с нейтралами можно считать автобой на сервере мгновенно.

**Расширяемая карта (для Сезонной Пустоши)**
- Карта мира хранится чанками 32×32 клетки в PostgreSQL. Чтобы расширить мир, по краям добавляются новые чанки с местами для замков, а старые игроки остаются на своих местах.
- Клиент подписывается только на чанки вокруг своих героев и замков, поэтому размер мира почти не влияет на трафик и скорость на телефоне.
- Размер мира и число мест задаются конфигом сезона и админ-командой, а не в коде.
- Масштабирование: сначала один процесс на мир, затем разбиение на регионы (группы чанков) по разным процессам через Redis. Растём по шагам: 200 → 500 → 1000+ игроков на мир, при переполнении открывается новый мир.

**Структура репозитория**
```
/client   Phaser + Vite, Pi SDK
/server   Colyseus, Pi API (auth, payments), REST для магазина
/shared   правила, типы, данные юнитов/заклинаний (JSON)
/maps     карты из Tiled
```

## 4. MVP (первая играбельная версия)

1. Вход через Pi (Testnet, sandbox).
2. Лобби: создать партию или присоединиться по коду, 2 игрока.
3. Одна карта, 2 фракции по 4–5 юнитов, 1 герой на игрока.
4. Карта приключений: перемещение, 3 ресурса (золото, дерево, руда), шахты, сундуки, нейтралы.
5. Замок: 5–6 зданий, найм отрядов раз в «неделю».
6. Тактический бой на гексах: движение, атака, ответный удар, стрелки, 3–4 заклинания.
7. Победа/поражение, переподключение при обрыве связи.
8. Один тестовый платёж за косметику, чтобы проверить весь цикл Pi-платежей.

**После MVP:** асинхронные партии и уведомления, рейтинг и матчмейкинг, 3–4 игрока, новые фракции, прокачка героя и навыки, кампания против ИИ, магазин косметики, реклама Pi Ad Network, подача на Mainnet.

## 5. Порядок работ

1. Создать репозиторий и каркас (client/server/shared), вывести пустую сцену Phaser в Pi Browser через sandbox.
2. Pi-авторизация с проверкой токена на сервере.
3. Карта приключений в одиночном режиме на общих правилах.
4. Перенос логики на сервер Colyseus, игра вдвоём.
5. Тактический бой.
6. Замок, ресурсы, найм.
7. Тестовый платёж.
8. Графика, звук, полировка, закрытый тест в Testnet.

## 6. Как разработчик зарабатывает на игре

Все платежи игроков идут в Pi на кошелёк приложения, который создаётся в Developer Portal. С Mainnet эти Pi реальные, их можно вывести на личный кошелёк и продать на бирже, где Pi торгуется. Правила Pi не запрещают зарабатывать. Они запрещают другие валюты и платежи мимо Pi SDK, а также вывод игроков на внешние сайты для оплаты.

**Источники дохода, в порядке важности**

| Источник | Что продаём | Цена-ориентир | Почему безопасно |
|---|---|---|---|
| Магазин косметики | Облики героев и замков, флаги, эффекты заклинаний, рамки профиля | 0.5–5 Pi | Не влияет на силу, игроки не жалуются на pay-to-win |
| Боевой пропуск на сезон (4–6 недель) | Бесплатная и платная ветка наград за игру, в платной только косметика | 3–10 Pi | Стабильный повторяющийся доход каждый сезон |
| Премиум-аккаунт (на месяц) | Больше одновременных асинхронных партий, расширенная статистика, приватные турниры для друзей, свой цвет ника | 1–3 Pi в месяц | Удобство вместо силы |
| Платный одиночный контент | Кампании против ИИ, наборы карт и сценариев | 2–8 Pi за кампанию | Не касается PvP-баланса |
| Сила героя (решение владельца: во всех режимах, без ограничений) | Прокачка героя, артефакты, ускорение опыта, ресурсы | 0.5–5 Pi | Чтобы слабые игроки не уходили, подбор соперников идёт по силе армии и героя |
| Реклама Pi Ad Network | Rewarded-видео по желанию игрока: второй шанс в кампании, ежедневный сундук с косметикой | Доля от дохода рекламной сети | Становится доступна после листинга приложения в экосистеме Pi |
| Поддержка разработчика | Кнопка «поддержать» с упоминанием в титрах | Любая сумма | Добровольно |

Цены нужно подбирать по реальной покупательной способности Pi на момент запуска. Цифры в таблице только ориентир.

**Чего не делать, чтобы не потерять листинг и не нарваться на закон**
- Платный вход в матч с призом в Pi. Это ставки на исход игры, по сути азартная игра.
- Лутбоксы за Pi со случайными наградами. Во многих странах они приравнены к азартным играм. Если нужны сундуки, пусть открываются за игровое золото или показывают содержимое заранее.
- Выплаты игрокам в Pi за победы (app-to-user) пока не включать. Это расход, а не доход, и он привлекает ботов.

**Что заложить в код с первого дня**
- Таблица покупок в PostgreSQL: кто, что, paymentId, txid, статус. Покупка выдаётся только после `complete` на сервере.
- Обработка незавершённых платежей при каждом входе (`onIncompletePaymentFound`).
- Каталог товаров на сервере, клиент не передаёт цену. Иначе цену можно подделать.
- Простая аналитика: сколько игроков, сколько платят, средний чек, удержание на 1-й, 7-й и 30-й день. По ней видно, какие товары работают.

**Порядок запуска монетизации**
1. MVP: один косметический товар, чтобы проверить весь цикл платежа на Testnet.
2. Закрытый тест: магазин косметики и премиум-аккаунт.
3. Выход на Mainnet: первый боевой пропуск.
4. После листинга: реклама Pi Ad Network и платные кампании.

Реальный доход зависит в основном от числа активных игроков. Поэтому игра должна быть бесплатной и честной, а платить игроки будут за красоту, удобство и дополнительный контент.

## 7. Как сделать игру интересной

Без этого раздела получится ещё одна копия «Героев», которая проиграет оригиналу. Ниже то, что даёт игре своё лицо и держит игроков.

**Главная фишка: Сезонная Пустошь**
- Кроме обычных партий есть одна общая карта мира на сезон (4–6 недель), где играют все сразу.
- Игрок получает на ней свой замок. Раз в день он делает ход героем: исследует, захватывает шахты, нападает на соседей.
- Игроки объединяются в кланы и вместе держат территории. В центре карты стоит Цитадель, и клан, который удержит её к концу сезона, получает награды и своё имя в зале славы.
- Бои на общей карте идут в обычном тактическом режиме, а если соперник не в сети, за него воюет ИИ.
- Этого нет ни в «Героях 3», ни в HotA. Заходить раз в день удобно на телефоне, а клан даёт причину возвращаться.

**Нет ожиданию**
- На карте все ходят одновременно, пошагово только в бою.
- Таймер хода и шахматные часы на партию.
- Асинхронный режим с уведомлением «ваш ход».
- Бои с нейтралами можно сыграть автобоем за секунду.

**Всегда есть с кем играть**
- Кампания против ИИ из 3 глав с сюжетом, по одной на фракцию.
- Ежедневное испытание: одна и та же карта для всех, таблица лучших по очкам.
- ИИ заменяет игрока, который вышел из партии.

**Честно при платной силе** (владелец выбрал продажу силы без ограничений)
- Подбор соперников по силе героя и армии, а не только по рейтингу.
- Отдельные лиги: «Открытая», где разрешено всё, и «Турнирная», где все стартуют одинаково. Турнирная лига даёт лучшую косметику и зал славы.
- Бесплатный игрок тоже может заработать артефакты игрой, просто медленнее.

**Лёгкий вход**
- Обучение на 5 минут: первый бой, первый замок, первый захват шахты.
- Подсказки при наведении: сколько урона нанесёт удар, сколько отрядов погибнет.
- Первые 3 партии против ИИ-новичка.

**Удержание**
- Ежедневные задания и награда за вход.
- Коллекция героев: у каждого своя способность, их хочется собрать всех.
- Реплеи боёв, которыми можно поделиться.
- Сезоны с новой картой, новым героем и новыми правилами (например, «сезон вечной зимы»: ресурсы добываются медленнее).

**Порядок внедрения:** обучение, бои с ИИ и одновременные ходы входят в MVP. Ежедневное испытание и лиги появляются к закрытому тесту. Сезонная Пустошь и кланы выходят к запуску на Mainnet как главная новинка.

## 8. Что ещё нужно топовой игре

Уже работает в прототипе: снаряжение героя (10 слотов, 14 артефактов, 4 редкости, комплект), выбор навыка на каждом уровне, книга заклинаний (Молния, Лечение, Ускорение), удача и мораль, способности существ, прогноз удара перед атакой, автосохранение.

**Глубина игры**
- 6 фракций к году после запуска, у каждой 7 существ с улучшенными версиями и своя механика (например, Нежить поднимает павших после боя).
- 4 школы магии (огонь, вода, земля, воздух) по 5 уровней, гильдия магов в замке.
- Дерево навыков героя вместо простых бонусов: Лучник, Тактика, Некромантия, Логистика, Дипломатия.
- Уникальные герои с личной способностью и историей, коллекция на 30+ героев.
- Осада замков: стены, башни, ворота, катапульта.
- События на карте: недели монстров, ярмарки, вулканы, караваны.

**Социальное**
- Друзья, личные сообщения, чат клана с модерацией.
- Кланы: общая казна, клановые здания, войны кланов в Сезонной Пустоши.
- Турниры по выходным, таблицы лидеров, реплеи и режим зрителя.
- Реферальная программа Pi: награда за приглашённого друга.

**Качество**
- Спрайты художника и анимации ударов, магии и смертей.
- Музыка для каждой фракции и звуки интерфейса.
- Языки: русский, английский, плюс языки крупнейших сообществ Pi: вьетнамский, корейский, китайский, индонезийский, филиппинский, хинди.
- Быстрая работа на слабых телефонах: загрузка до 10 секунд, 60 кадров на карте.
- Защита от читов на сервере и от мультиаккаунтов (Pi KYC помогает).

**Живая игра (LiveOps)**
- Новый сезон каждые 4–6 недель: карта, герой, артефакты, правило сезона.
- Праздничные события и лимитированная косметика.
- Аналитика: удержание, воронка обучения, где игроки бросают, какие покупки работают.
- Опросы игроков и открытый список изменений.
